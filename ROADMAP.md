# AI & Machine Learning Engineering Roadmap

**Professional goal:** Become a highly competitive AI Engineer / Machine Learning Engineer for international technology companies.

**Duration:** 18 months  
**Time commitment:** 20 hours/week  
**Estimated total:** 1,560 hours  
**Primary programming language:** Python  
**Target level:** Professional / Production-ready

---

## 1. Professional Profile & Strategy

### Background

- BSc in Applied Mathematics.
- Professional experience as a Full Stack Developer at Telefónica.
- Experience in cryptography and security-related software development.
- Programming experience in Python, C/C++, Git, Docker and Linux.
- Mathematical foundations in statistics, probability, optimization, linear algebra and numerical methods.

### Career Objectives

Target positions:

- Machine Learning Engineer
- AI Engineer
- Applied AI Engineer
- LLM Engineer
- AI Security Engineer

### Differentiation Strategy

Build a profile combining:

1. Strong mathematical foundations.
2. Classical Machine Learning and Deep Learning.
3. LLM engineering and AI Agents.
4. Production-level software engineering.
5. AI Security and applied cryptography.

The objective is not simply to learn how to use AI APIs, but to understand, implement, evaluate, optimize and deploy AI systems.

# 7. Progress Tracking

Progress must be documented continuously.

For each phase:

1. Complete the theoretical foundations.
2. Implement the concepts independently.
3. Solve practical exercises.
4. Document findings and limitations.
5. Publish code and documentation.
6. Review the exit criteria before advancing.

Progress should be measured by demonstrated technical ability, not merely by completed courses.
